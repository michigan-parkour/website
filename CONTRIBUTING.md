# Contributing

Use pull requests for all changes.

This repository updates the live `https://michiganparkour.com` site. Do not make
normal content changes in the old `umichparkour.com` website or archived
GitHub Pages copies.

1. Create a branch from `main`.
2. Make the site change.
3. Preview locally with `npx serve .`.
4. Open a pull request.
5. Wait for the Cloudflare Pages preview URL.

Keep copy clear, accurate, and compliant with University student organization naming and trademark rules.
